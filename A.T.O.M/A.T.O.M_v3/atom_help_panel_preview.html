    ARTIFICIAL TERMINAL OPERATIONS MODULE
>>> ARTIFICIAL TERMINAL OPERATIONS MODULE <<<
SYSTEM TOOLS & CAPABILITIES
[ WEB SEARCH ]
Search the internet for real-time or factual information.
▸ search google for latest stock price of NVIDIA
▸ who is the current prime minister of Japan?
[ FILE OPERATIONS ]
Read, write, append, or list files on your local disk.
▸ read file C:/Users/Docs/notes.txt
▸ write file log.txt with content 'Task Completed'
[ SYSTEM COMMANDS ]
Control hardware, volume, and launch applications.
▸ open notepad
▸ set volume to 50
[ CALCULATE ]
Perform maths or unit conversions.
▸ calculate (45 * 2) / 10
▸ convert 100 kilograms to pounds
[ MEMORY ]
Store or recall facts between sessions.
▸ remember my keys are in the top drawer
▸ what did I tell you about my keys?
[ SUMMARIZE ]
Extract key points from PDF, DOCX, or TXT files.
▸ summarize file C:/Downloads/research_paper.pdf
[ SHELL ]
Execute safe, read-only terminal commands.
▸ run command ipconfig
▸ ping google.com
QUICK COMMANDS
time / date  → Shows current system time and date.
battery status  → Shows current battery percentage.
sys info  → Real-time CPU and RAM usage.
who are you?  → Details about A.T.O.M's origin.
/help  → Show this panel.
/clear  → Clear the terminal output.
/model  → Show the active model name.
quit / exit  → Terminate the session.
Type your request in natural language. A.T.O.M will automatically determine the best tool to use.
